# 负责人模块演示与交接

## 启动

先按 README 安装、配置、迁移和种子，运行 npm run build 和 npm run start:demo。开发者工具导入根目录。此命令只监听本机，显式启用开发身份和真实本地图片上传。密钥从本机 .env 读取后手动输入登录页，不能写进源码、截图或聊天。

## 演示顺序

1. 游客首页浏览，搜索正文/话题/猫名，进入七天热帖与详情；点击猫咪标签跳 A 的档案入口。
2. 我的→登录→开发身份登录（真实微信需先配置账号）。从详情触发登录后返回原页面，postId 和输入保留。
3. 发布：输入文字，选图片（可零张），选择零个或多个话题/猫；同名猫按编号选择。提交后打开详情，首页刷新可见。
4. 点赞、取消点赞；文字评论、选定评论回复。自己不收自己的通知；回复时通知帖主和被回复作者，去重。消息展示和已读由 B 完成，此处可通过数据库/测试验证通知生成。
5. 模拟上传或提交网络故障：输入保留；结果未知时锁定当前提交，点击重试原请求。发布/评论只生成一条记录，点赞采用同一目标状态。
6. 作者确认删除；首页、搜索、热帖、关联帖和图片公开链接均按可见性排除。隐藏需 C 实现管理入口，测试直接准备隐藏状态验证公共规则。
7. 地图依次选择三个示例区域，观察选中样式、猫列表和空状态。快速切区不显示旧请求结果；档案交由 A，返回地图后刷新并保留有效选区。

## 分工边界

A/B/C 页面、个人消息和已读、管理写入仍是占位/501。负责人实现通知生成，不代替 B 完成通知列表。图鉴基础查询可用，但完整档案页面仍由 A 接手。C 需使用帖子行锁、公开可见性谓词和事务日志，避免绕过本轮规则。

## 验收边界

真实 MySQL、真实本地文件上传、编译页面 JS 经 HTTP 的链路已验证。尚未运行微信开发者工具 WXML/WXSS 编译、平台模拟器或真机；微信适配的注入测试不是平台认证。AppID/AppSecret、合法域名、云存储、真实底图与授权资料仍是后续外部依赖。

本地保存图片不可由另一台电脑直接访问；组员启动自己的环境或在确定共享测试服务后接入。没有开通付费资源，也没有部署公开服务。
