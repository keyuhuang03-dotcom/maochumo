# 产品效果图 UI 对照

依据：父目录交付文档中的《猫出没微信小程序需求说明书-最终版.docx》，读取其中的首页、校园地图、帖子详情、搜索、热帖、发布、Tag选择及成功页图。原Word和原始素材保持不变。

| 效果图 | 代码位置 | 本轮内容 |
| --- | --- | --- |
| 首页 | features/community/home；components/post-card | 浅绿底、搜索条、热帖摘要、带边框信息流、图片和Tag、点赞评论 |
| 帖子详情 | features/community/detail | 作者时间、正文图集、标签、互动、评论、底部固定发送栏 |
| 搜索与热榜 | features/community/search、hot | 输入行、筛选状态、浅米白排名条目 |
| 发布帖子 | features/community/publish | 大输入区、图片选择、标签摘要、独立选择入口、底部发布 |
| 选择Tag | features/community/tags | 话题与猫咪分组、多选、搜索、完成后回传草稿 |
| 发布成功 | features/community/success | 成功提示、查看帖子和返回入口 |
| 校园地图 | features/campus-map | 手绘底图副本、滚动、区域筛选及猫咪面板 |

路径相对miniprogram。原型中的作者、照片、赞评数、红点属于示例，界面继续展示真实业务数据；没有图片的数据不会插入虚假照片。A/B/C完整业务页面没有在本轮冒充完成。

地图文件为现有校园手绘地图v4的JPEG压缩副本，约330KB，避免直接放入约2.4MB的原图。它是演示素材，地名和范围仍待核验。图标为项目自绘线条，不引入图标库依赖。

## 实际检查

在微信开发者工具2.02.2609250、iPhone模拟器内检查首页、详情、手绘地图、发布和Tag选择。话题与同名猫的稳定ID选项能够选择，并将标签回传发布草稿；过程中未见业务错误。尚未进行真机截图比对，也不宣称像素级完全一致。原生tabBar、真实内容长度、数据空缺与原型有合理差别。

业务验证继续执行npm run check、npm run test:page、npm run test:owner-pages；后者覆盖真实HTTP上传、发布/评论丢失响应重试、PostCard点赞目标重试和地图乱序保护。平台自动热重载偶发样式缺失问题已通过构建完整产物后再更新输出目录处理。
