# 决策与未决事项

## 本阶段确定

2026-11-10 用户本次要求优先，其次首期开发执行基线 V2.2，再对照需求最终版、系统设计视觉优化版及含方法类图说明。原有 Word、图和素材只读，不上传整套历史资料。

原生微信小程序 TypeScript；统一 Fastify 5 模块化单体；mysql2 参数化 SQL + 明文 SQL 迁移。选型理由：Fastify 自带路由、JSON Schema 校验和注入测试；mysql2 内置 TS、连接池、prepared statements，课程成员能直接读 SQL，避免七天内再学习大型 ORM。没有引入微服务、MQ、Redis。依赖为精确版本，完整树由 lockfile 固定。

官方兼容性资料（2026-11-10 核查）：

- [Fastify v5 迁移指南](https://fastify.dev/docs/v5.8.x/Guides/Migration-Guide-V5/)：Node 20+；团队选仍在 LTS 维护的 Node 24。
- [Fastify 支持策略](https://fastify.dev/docs/latest/Reference/LTS/)：支持期覆盖 Node LTS 线。
- [mysql2 官方 TS 文档](https://sidorares.github.io/node-mysql2/docs/documentation/typescript-examples)：原生类型与 Node types。
- [mysql2 官方文档](https://sidorares.github.io/node-mysql2/docs/documentation)：连接池及预处理查询。
- [Node 官方发布记录](https://github.com/nodejs/node/releases)：Node 24 LTS。
- [MySQL 8.4 官方手册](https://dev.mysql.com/doc/refman/8.4/en/)：团队使用 8.4 系列；本机现有 9.7 实测单列记录，不冒充 8.4 验证。
- 微信官方快速入门页面工具访问失败；平台能力尚待微信开发者工具与账号验证，不据此声称兼容已通过。

字符串 ID 最大 64 字符，不使用 JS 大整数；猫名非唯一；话题和猫均可选多对多；猫主要区域非空且唯一。JSON 存别名/照片数组。公开只读 published，隐藏/删除旧链接均 404。

技术实现口径：正文按 Unicode code point（Array.from）计数，不把组合字符当一个视觉字；2000 字/9 图为上限，至少正文或图片一项。该计数算法是本阶段技术选择，发布接口尚未实现，须前后端共用；图片规格仍待定。首期不增加发布后编辑、恢复隐藏、GPS、举报或审核。
